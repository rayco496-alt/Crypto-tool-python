# Cripto-Tool Python

Herramienta CLI (Command Line Interface) desarrollada en Python para operaciones criptográficas.

## Características
*   Cifrado simétrico (AES-GCM).
*   Cifrado híbrido (RSA + AES).
*   Firmas digitales (RSA).
*   Generación y verificación de HMAC.
*   Generación de pares de llaves RSA.

## Uso
1. Clona el repositorio.
2. Instala dependencias: `pip install pycryptodome`.
3. Ejecuta: `python3 Servicio_Criptográfico.py`
